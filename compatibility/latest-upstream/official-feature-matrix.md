## 判断方式

当前[接口与交付审查](./official-interface-audit.md)已逐项对应19项历史依赖及62个调用/7个流入口。候选0.1.80-latest.0已从alpha.1/alpha.2目录清理 `agentPresets/copy` / `agentPresets/deletePreset`，目标Host在转发前拒绝旧请求；实际生产中转管理连接已验证，旧0.1.6契约保留。不修改DSH来补齐归档管理。

“已通过”仅指下表写明的真实场景；“待复验”表示代码/官方接口存在候选路径，不能沿用修改版的通过结果。“取消”表示当前实现需要本体补丁，纯官方交付不提供。能力协商为 true 只说明服务存在，不等于行为通过；管理权限与服务可用性分别检查，不能因管理能力可用就自动授予设备管理权。

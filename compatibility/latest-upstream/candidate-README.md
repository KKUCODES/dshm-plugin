# DSHM 电脑插件兼容候选

此包是未发布的本地候选，插件版本以本包 `package.json` 的 version 为准。目标 DSH 版本以其中的精确 peerDependencies 为准：候选分别针对官方预发布 `0.2.1-alpha.1` 或 `0.2.1-alpha.2` 构建，两者不能混装，也不放行任意未来版本。DSHM App 的 SDK 版本须与目标电脑一致。

插件负责连接 DSHM 手机客户端与电脑 DSH。手机使用自己的聊天页面，电脑执行任务，公网中转负责传输。配对仍需要电脑批准；开放注册模式不会跳过设备授权。

安装后通过原来的 `pnpm dsh web` 启动。在插件页填写中转服务根地址、注册电脑，再开启远程连接。生成配对链接，在手机领取，回到电脑核对设备指纹并批准。开放注册免去电脑注册密钥；手机仍需配对与批准。HTTP 可用并会提示连接未加密。

已注册后点击“修改服务地址”：同一后端换域名、端口或 HTTP / HTTPS 时，确认新地址可信后验证当前电脑凭据，保留电脑身份和设备授权；更换后端则重新注册，个人模式需新服务的注册密钥。取消或验证失败保留原连接，成功后保留原开启状态。手机需要使用新配对链接重新连接；更换后端不会自动撤销旧服务授权。

本候选仅使用官方公开接口与插件扩展点，不要求 DSH 本体补丁、专用 preload 或修改版。此归档不包含 DSHM App、公网后端或账号凭据，不能以插件成功安装推断完整 Remote 可用。完整手机能力此前在固定 alpha.2 / 插件 0.1.80 组合完成本地验收；新增地址修改另行验证，不能沿用为 alpha.1 或任意第三方插件的完整支持结论。

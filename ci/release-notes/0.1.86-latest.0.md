DSHM 电脑插件开发预览 / Desktop plugin development preview

### 本次更新

- 新增官方 **DSH 0.2.1-rc.2** 核心连接支持，保留旧版载荷。
- 运行时采用有界 semver 范围与实际服务、模块图和协议能力检查；缺少能力时明确拒绝，不绕过权限。
- 适配 rc.2 官方 Fetch/事件流的原生 Peer 参数；不伪造身份，不修改 DSH 本体。
- 默认 GitHub 预编译包覆盖已验的 **0.2.0-rc.2 / 0.2.1-alpha.2 / 0.2.1-rc.2**；alpha.1 保留独立归档。

### 安装与配套版本

配套更新[DSHM 0.1.0-preview.6 APK](https://github.com/KKUCODES/deepseek-harness-mobile/releases/tag/v0.1.0-preview.6)，然后重启 DSH。中转服务无需升级。

```text
dsh plugin --profile web add github:KKUCODES/dshm-plugin
```

下载 `.tgz` 时按电脑 DSH 版本选择文件名中的 `dsh-<版本>`。每版附 SHA-256 与兼容元数据。此版不包含此前独立插件适配分支的内容。

261 项插件 Vitest、12 项包/端点检查与三版原官方 CLI → 隔离生产中转实现 → MuMu 的核心连接检查通过。alpha.1 保留构建支持，不据此声明新一轮手机连接实测。本轮没有调用真实模型，没有完整 Electron、真机、公网、全部插件/审批/Office 验收；用户报告的同步 CPU 死循环未独立复现。

### What's changed

- Official DSH **0.2.1-rc.2** core connectivity, bounded compatibility ranges and real capability checks.
- Forward the original official Peer for Fetch and event streams; no fabricated identity, permission bypass or DSH core modification.
- The shared GitHub package supports the tested **0.2.0-rc.2 / 0.2.1-alpha.2 / 0.2.1-rc.2** hosts. Alpha.1 keeps its separate archive.

Pair with **DSHM 0.1.0-preview.6**, restart DSH, and select the matching DSH-version `.tgz` if downloading manually. No relay upgrade is needed. The separate plugin-adaptation branch is excluded.

261 plugin tests, 12 packaging/endpoint checks and isolated MuMu core connections against three official CLI versions passed. This is not full Electron, physical-device, public-network, model or third-party-plugin validation. The reported synchronous CPU loop was not independently reproduced.

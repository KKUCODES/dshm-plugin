DSHM 电脑插件开发预览 / Desktop plugin development preview

### 本次更新

- 对插件资源生成 SHA-256 指纹；手机用原认证链路进行 HEAD 校验，未变化的资源无需重传正文。资源更新、删除与访问范围继续由电脑原资源注册表确认。
- 为工作区、会话列表和聊天历史提供只读基线与差量编码，减少重连时重复传输。旧 App 保持原行为，写消息和审批不缓存、不重放。
- 缓存按设备、权限和 DSH 版本隔离；缺失或失效基线会回退完整读取。无需修改官方 DSH，也无需部署新版中转服务。

### 安装与配套版本

完整优化需更新[DSHM 0.1.0-preview.4](https://github.com/KKUCODES/deepseek-harness-mobile/releases/tag/v0.1.0-preview.4)。GitHub 默认安装包支持官方 **0.2.0-rc.2 / 0.2.1-alpha.2**：

```text
dsh plugin --profile web add github:KKUCODES/dshm-plugin
```

下载 `.tgz` 时，请选择文件名中 `dsh-<版本>` 与电脑 DSH 完全匹配的归档；另提供 alpha.1 专用包。每个归档附 SHA-256 和兼容元数据。

本次 alpha.2 原 CLI＋生产网关实现＋MuMu 已验证缓存重开、实时更新、损坏回退和电脑离线恢复；rc.2 的新缓存路径只做构建核对。构建和安装检查不代表所有版本、设备、第三方插件或公网环境均已完成运行验收。

### What's changed

- Desktop-authoritative resource fingerprints and authenticated HEAD revalidation let the updated app reuse unchanged assets.
- Read-only baselines and deltas reduce repeated workspace and chat transfers; messages and approvals are never cached or replayed.
- Binding, permission and DSH-version isolation, with full-read fallback. No DSH core patches or relay deployment are needed.

Pair with DSHM **0.1.0-preview.4**. The default GitHub package supports official DSH 0.2.0-rc.2 / 0.2.1-alpha.2. Choose the exact DSH-version archive when downloading a `.tgz`; alpha.1 has its own archive. SHA-256 and compatibility metadata are included. New cache runtime checks used official alpha.2 with MuMu; rc.2 received build checks in this iteration.

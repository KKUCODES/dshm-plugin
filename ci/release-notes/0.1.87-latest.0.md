DSHM 电脑插件开发预览 / Desktop plugin development preview

### 本次更新

- 通用大响应分块：首次快照、历史页RPC和实时大事件不再因单帧超过2MiB直接失败。
- 64KiB块、四块确认窗口、完整性校验及有界队列；取消、断线和超时清理原官方订阅，保持业务事件顺序。
- 按App、中转与插件能力协商启用；旧端保持原格式。保留既有DSH版本范围和权限检查，不修改DSH，不包含独立插件适配分支。

### 配套更新

更新[DSHM preview.7 APK](https://github.com/KKUCODES/deepseek-harness-mobile/releases/tag/v0.1.0-preview.7)，重启DSH，**自建中转同步升级到包含协议提交 `94183d0` 的版本**。只有三端均支持时才启用大响应分块；旧端仍有原2MiB限制。

默认GitHub安装包仍供官方DSH 0.2.0-rc.2 /0.2.1-alpha.2 /0.2.1-rc.2共用，alpha.1保留独立归档。手动下载时按文件名中的DSH版本选择 `.tgz`，附SHA-256及兼容清单。

261项插件测试、适用后端114项及新增HTTP/WS专项通过。官方rc.2＋Android12模拟设备已验证约2.55MB首快照、2.52MB历史页及重连后大快照；实时大事件在真实传输链路合成联调中验证。无模型调用，不代表完整真机、Electron、所有第三方插件或Office专项复验。

### What's changed

- Generic chunked responses for initial snapshots, history RPC pages and large live events, retaining the2MiB physical-frame limit.
- 64KiB chunks, a four-chunk acknowledgement window, integrity checks and bounded queues. Cancellation, timeout and disconnect release the original subscription.
- Negotiated capability with legacy fallback; existing DSH ranges and access checks remain. No DSH core changes or separate plugin-adaptation work.

Requires **DSHM preview.7** and a relay containing protocol commit **94183d0** for large responses. Restart DSH after updating. Older peers continue using the original protocol and limit. Select the archive matching your DSH version; alpha.1 retains its separate build.

261 plugin and114 applicable relay tests passed. An unmodified official rc.2 and Android12 emulator passed synthetic large-chat snapshot, older-page and reconnect checks. This is not a full physical-device, Electron, model or arbitrary third-party-plugin audit.

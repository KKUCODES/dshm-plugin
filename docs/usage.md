# 安装与使用

DSHM 插件装在电脑上的官方 DSH 中。手机用 DSHM 的 Remote 连接它，继续电脑上的会话；普通聊天则使用手机自己保存的 DeepSeek Key。

## 准备

| 部分 | 获取与版本选择 |
| --- | --- |
| 电脑 | 官方 DSH；当前下载包分别面向 `0.2.1-alpha.1` / `0.2.1-alpha.2`，完整核心本地验收使用 alpha.2。 |
| 插件 | 从 [Actions](https://github.com/KKUCODES/dshm-plugin/actions/workflows/plugin-build.yml) 下载 `0.1.82-latest.0` 对应版本的 Artifacts，解压后取得 `.tgz`，需要登录 GitHub。 |
| 手机 | 从 [DSHM Releases](https://github.com/KKUCODES/deepseek-harness-mobile/releases) 下载已签名 Android 开发预览；使用前核对配套 DSH 与插件版本。 |
| 中转 | 手机和电脑都能访问的 DSH Mobile 中转服务。 |

插件 Release 当前仍是未发布草稿，普通用户通过 Actions 获取构建包；下载方式和保留期限见[插件下载说明](./releases.md)。`0.1.82` 已核验打包、文件与摘要，没有把它计作全量手机兼容验收。核心 Remote 的完整本地证据对应 `0.1.80-latest.0`＋官方 DSH `0.2.1-alpha.2`＋原配套 Android；`0.1.81-latest.0` 的[地址修改专项](../compatibility/latest-upstream/gateway-settings.md)另行记录。具体范围见[当前支持清单](../compatibility/latest-upstream/official-support.md)，历史归档安装见[本地安装记录](../compatibility/latest-upstream/official-installation.md)。

包名中的 DSH 版本必须与电脑一致，不要混装或直接换成任意更新版本。alpha.1 构建包不沿用 alpha.2 的完整手机验收结论。取得下面示例包仅说明可以开始安装和联调，不代表该下载组合已经完成上述所有验收。

## 1. 安装插件

在官方 DSH 的项目目录执行，将示例路径换成插件归档的实际位置：

```powershell
pnpm dsh plugin --profile web add 'C:\Downloads\dshm-plugin-0.1.82-latest.0-dsh-0.2.1-alpha.2.tgz'
pnpm dsh web
```

通过终端输出的登录链接打开 DSH。若安装时提示“下次启动后加载”，先在运行 DSH 的终端按 Ctrl+C，再执行原来的 `pnpm dsh web`。刷新网页或重启中转服务不会让旧 DSH 进程加载新插件。

插件不包含 DSH 本体，不需要替换或重新构建官方 DSH。

## 2. 连接中转

### 选择中转服务

**推荐自行搭建**，方便管理服务、数据与访问策略。搭建方式见[后端说明](https://github.com/KKUCODES/dshm-relay)。

不想自行搭建时，可使用项目维护者提供的[公共中转服务](http://118.31.20.47:18787)。在插件“服务地址”填写以下根地址：

```text
http://118.31.20.47:18787
```

公共服务为开放注册，不需要注册密钥；手机仍需一次性配对，并由电脑核对指纹后批准。该地址目前使用 HTTP，传输未加密，涉及敏感内容时建议自建并启用 HTTPS。

已经注册到其他服务的电脑，点击“修改服务地址”，选择“更换后端，重新注册和配对”，切换后生成新配对链接。详细步骤见[修改服务地址](#5-修改服务地址)。

### 注册电脑

在 DSH 的插件列表中打开 `@dsh-mobile/plugin`，填写服务根地址和电脑名称。等待页面检测注册模式，再点击“注册这台电脑”，随后“开启远程连接”。成功后会显示“已连接”。

| 注册模式 | 首次注册电脑 |
| --- | --- |
| 开放使用 | 不需要注册密钥。后端配置为 `REGISTRATION_MODE=open`。 |
| 个人使用 | 需要服务管理员提供的注册密钥，与后端 `ENROLLMENT_TOKEN` 一致。 |

注册成功后，插件保存这台电脑自己的凭据，正常启动 DSH 即可。首次注册密钥与普通聊天的 DeepSeek Key 是两种不同的凭据。

服务地址填写根地址，不加路径、查询参数或配对密钥。HTTP 和 HTTPS 均支持；HTTP 连接时会提示内容未加密。手机上的 `127.0.0.1` 指向手机自己，仅在同一台电脑或配置了测试映射时才适用。

如果需要运行本项目后端，数据库和地址配置见[后端说明](https://github.com/KKUCODES/dshm-relay)及[配置样例](https://github.com/KKUCODES/dshm-relay/blob/main/.env.example)。已有构建产物时，从后端目录启动：

```powershell
node --env-file=.env.local packages/gateway/dist/main.js
```

## 3. 配对手机

1. 在电脑插件页点击“生成一次性配对链接”。
2. 打开手机 DSHM 的 Remote，粘贴完整链接，再点击“继续配对”。
3. 电脑会显示等待批准的手机。对照手机显示的公钥指纹，勾选“我已核对设备公钥指纹”，点击“批准设备”。
4. 手机上点击“我已在电脑批准”，打开已有工作区和会话。

配对链接五分钟内有效，领取一次即失效。当前固定候选的电脑设置页提供链接；手机也可识别已有链接对应的二维码。开放注册不会跳过手机配对、身份校验或电脑批准。

手机与电脑共同参与同一个会话。手机发消息、切换模型或答复审批，会作用于这份电脑会话；也可以在已有工作区创建新聊天。

## 4. 管理访问

- **撤销访问：** 在设备列表点击“撤销访问”。该手机无法继续访问，重新连接需要重新配对。
- **关闭连接：** 点击“关闭远程连接”，暂停这台电脑的远程访问；重新开启后，未撤销的设备可尝试重连。
- **电脑管理：** 普通设备授权提供聊天与任务操作。管理电脑插件、工作区和设置需要单独“授予管理权限”，之后可以“收回管理权限”。

电脑和 DSH 需要保持运行。App 进程结束后不继续推送消息，重新打开后尝试重连。

## 5. 修改服务地址

在已注册的电脑插件页点击“修改服务地址”，选择修改方式，填写新服务根地址。编辑期间仍使用原连接。

| 修改方式 | 保存后会怎样 |
| --- | --- |
| 同一后端换地址，保留设备授权 | 用当前电脑凭据检查新地址，成功后保留电脑身份和设备授权。不需要再次填写注册密钥。仅适用于同一个后端换域名、端口或 HTTP / HTTPS。 |
| 更换后端，重新注册和配对 | 在新服务注册新的电脑身份。开放模式免密；个人模式填写新服务的注册密钥，不使用旧凭据。新服务不继承旧手机授权。 |

同一后端换地址时，需要勾选确认新地址属于可信的同一服务；插件随后才使用电脑凭据验证。更换后端时，确认手机需要重新配对后再提交。HTTP 可以保存，并继续显示未加密提示。

检查和保存成功后才切换连接，并保留原来的开启或关闭状态。取消、连接失败、凭据不匹配或保存失败，都不会替换原配置。若其他窗口已改过配置，请取消编辑后重新打开。

**手机需要使用新地址重新连接。** 当前 App 不会自动迁移已保存的服务地址；在电脑生成新的配对链接，回到手机重新配对并在电脑批准。电脑原有的会话和工作区不会因中转地址修改而迁移或删除。

更换后端不会自动撤销旧服务授权。需要停用旧手机时，应先在原服务的设备列表“撤销访问”，再更换后端。

## 使用范围

手机不创建新的电脑工作区，不提供手机命令输入或电脑 localhost 网站转发。其他插件、模型提供方和 DSH 版本是否兼容，以[支持清单](../compatibility/latest-upstream/official-support.md)中列明的范围为准。

公网部署、物理手机和官方 Electron 尚不属于当前已通过的验收范围。本地连接成功不等于这些环境也已验证。
